\# Contributing



Thanks for helping with this project.



\## Branches



\- `Master` holds the shared files (README, data, settings). It has no notebooks.

\- `student-data-analysis` is the plain Python version.

\- `numpy-version` is the numpy version.

\- `pandas-version` is the pandas version.



\## How to contribute



1\. Clone the repository and switch to the branch you want: `git checkout <branch>`.

2\. Create your own branch for the change: `git checkout -b my-change`.

3\. Make small commits with clear messages.

4\. Before you finish, bring in the latest shared files: `git merge Master`.

5\. Push your branch and open a pull request into the branch you started from.



\## Before you commit a notebook



Run it once to check the results (37 male, 68 female, averages about 81.85 and 83.56), then use Clear All Outputs so the changes stay small.



\## Data



`students-data.csv` has five columns: ID, class, gender, race, GPA. Do not add personal or real student data.
